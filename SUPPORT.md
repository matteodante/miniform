# Support

Miniform is community-supported and does not currently provide paid or guaranteed support.

## Where to ask

- **Questions, deployment help, and ideas:** [GitHub Discussions](https://github.com/matteodante/miniform/discussions)
- **Reproducible bugs:** [GitHub Issues](https://github.com/matteodante/miniform/issues/new/choose)
- **Security vulnerabilities:** private reporting described in [SECURITY.md](SECURITY.md)

Before posting, check the [documentation](docs/installation.md), [troubleshooting guide](docs/troubleshooting.md), existing issues, and existing discussions.

Include the Miniform version or commit, operating system, installation method, relevant configuration with secrets removed, and the smallest reproducible example. Never post session secrets, webhook secrets, mail credentials, submission contents, or unredacted logs containing personal data.
