## Scope

## Confirmed findings and fixes

| Priority | Finding | Fix and evidence |
| --- | --- | --- |
| High | JSON decoding converted numbers to `float64`, silently changing identifiers such as `9007199254740993` to `9007199254740992`. HTTP input, CLI input/output, email rendering, and webhook payloads were affected. | Added a domain-owned decoder using `UseNumber` and preserved stored JSON as `RawMessage` for output. Regression tests failed before the fix and pass afterward across all four flows. Malformed, non-object, and trailing JSON remain rejected by the public endpoint. |
| Medium | A Turnstile client timeout was treated like caller cancellation, ending retries and returning an invalid-captcha outcome instead of service unavailability. A response-body timeout also bypassed retries. | Check the caller's context separately from client deadlines. Retry client timeouts within the existing three-attempt policy and return `ErrTurnstileUnavailable` when exhausted. Tests cover timeouts before headers and during the body, plus caller cancellation and deadline expiry. |
| High, caught during review | Matcha 0.16.0 automatically pulls an image during `Reload`. Without adapting the caller, reload and database restore could change the running image, and update could pull again after stopping the application. | Set `SkipPull` in `startDeployment`. Regression assertions verify no pulls on reload or restore and exactly two explicit pulls before stop on update. They failed before the fix; the deployment suite, `make check`, and race tests passed afterward. |
| High, test toolchain | `npm audit` reported a high-severity vulnerable `undici` dependency. GitHub also had five open alerts for the same E2E dependency. | Updated the lockfile to `undici` 6.29.0. `npm audit` now reports zero vulnerabilities. These alerts concern the Node test toolchain, not the Go runtime; remote alerts remain attached to the unchanged default branch until the fix is merged. |
| Medium | The pinned golangci-lint version failed type checking against the locally installed Go 1.27 standard library, blocking `make check`. | Updated golangci-lint to 2.14.0, its verified download hashes, and deadcode to 0.51.0. Lint and the complete `make check` target pass. |
| Low | `.dockerignore` did not exclude `.tools` and `.gopath`, allowing local tool caches into the build context. | Added both exclusions and verified them with Moby's Docker ignore matcher. The same verification confirmed that dependency `LICENSE.md` files were already included; no license inclusion fix was needed. |
| Low | `SECURITY.md` still listed 0.2.x as supported despite the published 0.3.0 release and its latest-release-only policy. | Updated the support table to 0.3.x. |

The JSON fix preserves future inputs and correctly stored existing values. Previously rounded values cannot be reconstructed without their original source.

An earlier Apple Container startup attempt failed during kernel installation, and that service was stopped.
